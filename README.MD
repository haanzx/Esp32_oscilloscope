# NuxScope

A modernized fork of Esp32_oscilloscope by Bojan Jurca.

NuxScope is an ESP32-based digital oscilloscope with a redesigned architecture, migrated to PlatformIO, and improved web interface.

## Original Project

This project is based on:
https://github.com/BojanJurca/Esp32_oscilloscope

Thanks to Bojan Jurca for the original ESP32 oscilloscope project.

## Changes from the original project

- Migrated from Arduino IDE to PlatformIO
- Reorganized project structure
- Improved firmware architecture
- Redesigned web interface
- Backend improvements
- (Future) Additional oscilloscope features

## Features

- Real-time signal visualization
- ESP32 high-speed ADC sampling
- Web-based user interface
- Lightweight embedded firmware

## Hardware

- ESP32 DevKit V1
- Analog input channels
- Wi-Fi connection
